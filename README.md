# Hi, I'm David

I'm a security engineer in Bellevue, WA. Outside of work I mostly build tools for myself, and I'd rather run them on my own hardware than sign up for yet another service.

## What I'm working on

- **Forge**: a self-hosted workout tracker. Tell it your goals and what equipment you have, follow the plan it builds (or ignore it and train freely), log your sets, and see how you're progressing. It pulls in activities from Garmin too. Hono API, React frontend, Postgres with Drizzle.

- **Homelab**: a k3s cluster on an Orange Pi 5, managed with Flux GitOps. It runs Home Assistant, Immich and my side projects behind Traefik, with Prometheus and Grafana for monitoring, Kyverno and Trivy for policy and image scanning, and ZFS storage backed up with Velero.
